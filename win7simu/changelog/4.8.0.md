<ReleaseSection platform="core">

* Added several enhancements for window manager:
  * Window's size and state are stored so that for the next time, it opens exactly as the last session.
  * Window snapping and resizing now works correctly for RTL languages
  * Several gestures to interact with a window are supported: drag the window's title bar to the top to maximize, drag to the left/right edge to fill half screen, double-click the title bar to maximize/restore the window etc.
* You can now select multiple files or folders, and perform bulk actions, e.g. cut, copy, restore, compress
* Windows Search is now fully functional:
  * Search works across [File Explorer](../simulated/fileexplorer.md), [Control Panel](../simulated/cpanel.md), and start menu.
  * Search behavior is tailored to faithfully match each OS theme.
* You can now compress multiple files and folders into a zip
* Added new screensaver: Starfield
* Added [Mahjong Titans](../simulated/mahjong.md)
* Added taskbar popup for network tray icon
* Windows XP variants and Ubuntu themes are now available for free
* Lifetime sponsor tier now unlocks all paid themes
* Several other bug fixes and improvements

</ReleaseSection>

<ReleaseSection platform="android">

* Added several enhancements for touch support:
  * Check boxes appear once an item is selected, enabling multi-selection
  * Tapping shows a small ripple where your finger touched
  * Holding draws a closing ring around your finger, and lifting your finger triggers the right-click
  * Dragging up a taskbar button opens its menu
  * Enhance control elements to better support finger touch
  * Window gestures are made to be fully touch-compatible.
* Added several enhancements for touchpad:
  * A two-finger tap now correctly triggers right-click
  * You can now scroll with two fingers instead of having to grab the scrollbar
  * Enhanced pointer speed with gesture-based acceleration
  * Added a Sensitivity slider for Touchpad in [Mouse](../simulated/mouse.md) settings

</ReleaseSection>
